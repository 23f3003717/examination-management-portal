# Demo guide (5–8 minutes)

1. Sign in as Admin and show the dashboard statistics.
2. Create a course, an examination and a rubric.
3. Create an Examiner account and sign in as that examiner.
4. Open the examination's slot-creation period/status and create an available slot.
5. Sign in as a Student, browse examinations, book the slot and show booking history.
6. Sign back in as Examiner, inspect booked students and submit a rubric-based evaluation.
7. Sign in as Admin and publish results; return as Student and show the published result.
8. Demonstrate CSV export with Redis and a Celery worker running.
9. Show the monthly report task and daily reminder task configuration.
10. Explain the SQLite ER diagram, API authorization and background jobs.
